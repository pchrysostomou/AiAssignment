# Project Summary
The Academic Suite is a sophisticated SaaS platform designed to enhance academic writing while maintaining educational integrity. It leverages advanced AI technologies to provide tools for essay generation, plagiarism detection, content analysis, assignment grading, and payment management. The platform operates on a dynamic pricing model based on word count and tool usage, with ongoing improvements to performance, user experience, and security.

# Project Module Description
The application consists of the following key modules:
- **User Management**: Handles user registration and authentication.
- **Essay Generation (The Architect)**: Generates essays with citation verification, ensuring minimum word counts and self-grading.
- **Plagiarism Checking (The Detective)**: Conducts plagiarism checks and provides interactive reports.
- **AI Detection (The Oracle)**: Identifies AI-generated content using a 3-agent consensus method.
- **Strict Grading (The Grader)**: Evaluates essays based on consensus from multiple AI models.
- **File Upload & Parsing**: Supports drag-and-drop uploads for various file types, limited to 25MB.
- **Stripe Payments**: Manages payments based on tool usage, including promo code support.
- **Real-time Streaming**: Offers live updates during essay generation and processing.
- **AI Support Bot (The Concierge)**: Assists users via a chat interface.

# File Description Inventory
- **app.py**: Core application logic, including user management, tool operations, payment processing, and AI model integration.
- **requirements.txt**: Lists necessary Python libraries for the application, updated for compatibility.
- **Procfile**: Specifies how to run the application in production using Gunicorn.
- **.env.template**: Template for environment variables needed to configure the application.
- **.env**: Contains sensitive configuration details (API keys, database URI).
- **ai_architect.db**: SQLite database file created at runtime to store user and essay data.
- **templates/**: Directory containing HTML files for various application views.
- **README.md**: Comprehensive documentation for installation, usage, and features.
- **start.bat**: Batch file to automate the setup process on Windows.

# Technology Stack
- **Backend**: Flask (Python), Flask-SQLAlchemy (SQLite DB), Flask-Login for authentication.
- **Frontend**: HTML/JavaScript with Server-Sent Events (SSE) for real-time updates.
- **File Handling**: PyPDF2 for PDF parsing, python-docx for Word document processing.
- **Payments**: Stripe for payment processing, supporting promo codes.
- **AI Models**: 
  - Claude 3.5 Sonnet (stable version ID `claude-3-5-sonnet-20240620`) with fallback to GPT-4o (Chancellor GPT).
  - Smart model discovery for Gemini to prevent errors.
- **Production Server**: Gunicorn for deployment.

# Usage
### Installation Steps
1. **Clone or create the project directory**:
   ```bash
   mkdir ai-assignment-architect
   cd ai-assignment-architect
   ```

2. **Create a virtual environment**:
   ```bash
   python -m venv venv
   venv\Scripts\activate  # Windows
   ```

3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Configure environment variables**:
   ```bash
   # Copy the template
   copy .env.template .env
   # Edit .env and add your API keys
   notepad .env
   ```

5. **Initialize the database**:
   ```bash
   python app.py
   ```

### Running the Application
Start the application:
```bash
python app.py
```

### Using the Application
1. Log in using the provided credentials.
2. Access the control center to select tools (The Architect, The Detective, The Oracle, The Grader).
3. Follow the prompts for each tool to upload documents or enter text and complete the associated tasks.
