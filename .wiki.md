# Project Summary
AI Assignment Architect - PRO SaaS is a high-end, commercial-grade AI writing platform designed to generate quality essays through an interactive, multi-agent system. The application integrates advanced AI models for drafting, refining, and optimizing essays while enabling users to upload documents, manage payments via Stripe, and track their writing progress in a visually engaging interface.

# Project Module Description
The application consists of several key modules:
- **User Management**: Handles user registration and authentication using Flask-Login.
- **Essay Generation**: Utilizes AI models (Claude, GPT-4o, Gemini) to create and refine essays through an iterative process.
- **File Upload & Parsing**: Supports drag-and-drop uploads of `.pdf` and `.docx` files, extracting text for AI processing.
- **Stripe Payments**: Integrates Stripe for processing payments, allowing users to purchase credits for essay generation.
- **Real-time Streaming**: Provides live updates on the essay generation process via Server-Sent Events (SSE).
- **Database Management**: Stores user data, generated essays, and payment records in an SQLite database.

# File Description Inventory
- **app.py**: Contains the core application logic, including routes, user management, essay generation, file handling, and payment processing.
- **requirements.txt**: Lists necessary Python libraries for the application, including Stripe, PyPDF2, and python-docx.
- **.env.template**: Template for environment variables needed to configure the application.
- **.env**: Contains sensitive configuration details (API keys, database URI).
- **ai_architect.db**: SQLite database file created at runtime to store user and essay data.
- **templates/login.html**: HTML template for user login and registration.
- **templates/dashboard.html**: HTML template for the main user interface to generate essays and view history.
- **README.md**: Comprehensive documentation for installation, usage, and features.
- **start.bat**: Batch file to automate the setup process on Windows.

# Technology Stack
- **Backend**: Flask (Python), Flask-SQLAlchemy (SQLite DB), Flask-Login for authentication.
- **Frontend**: HTML/JavaScript with Server-Sent Events (SSE) for real-time updates.
- **File Handling**: PyPDF2 for PDF parsing, python-docx for Word document processing.
- **Payments**: Stripe for payment processing.
- **AI Models**: Claude 3.5 Sonnet, GPT-4o, Gemini 1.5 Pro.

# Usage
### Installation Steps
1. **Clone or create the project directory**:
   ```bash
   mkdir ai-assignment-architect
   cd ai-assignment-architect
   ```

2. **Create a virtual environment**:
   ```bash
   python -m venv venv
   venv\Scripts\activate  # Windows
   ```

3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Configure environment variables**:
   ```bash
   # Copy the template
   copy .env.template .env
   # Edit .env and add your API keys
   notepad .env
   ```

5. **Initialize the database**:
   ```bash
   python app.py
   ```

### Running the Application
Start the application:
```bash
python app.py
```
