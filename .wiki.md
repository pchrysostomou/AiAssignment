# Project Summary
The Academic Suite is a sophisticated SaaS platform designed to enhance academic writing and maintain integrity in educational settings. It provides advanced tools for essay generation, plagiarism detection, AI content identification, and grading, all powered by cutting-edge AI technology. Users can upload documents and manage payments through Stripe, with flexible pricing based on word count and tool usage. The platform aims to improve writing quality while upholding academic standards, serving as an essential resource for students and educators.

# Project Module Description
The application consists of the following key modules:
- **User Management**: Handles user registration and authentication using Flask-Login.
- **Essay Generation (The Architect)**: Generates essays with citation verification and human-like writing.
- **Plagiarism Checking (The Detective)**: Conducts thorough plagiarism checks and produces detailed PDF reports.
- **AI Detection (The Oracle)**: Identifies AI-generated content and provides a probability score.
- **Strict Grading (The Grader)**: Evaluates essays through a consensus process involving three AI models.
- **File Upload & Parsing**: Supports drag-and-drop uploads of `.pdf`, `.docx`, and `.txt` files.
- **Stripe Payments**: Facilitates payments based on tool usage with tiered pricing.
- **Real-time Streaming**: Provides live updates during essay generation and tool processing.
- **AI Support Bot (The Concierge)**: Offers user assistance via a chat interface.

# File Description Inventory
- **app.py**: Core application logic, including routes for user management, tool operations, and payment processing.
- **requirements.txt**: Lists necessary Python libraries for the application, including Stripe and file handling libraries.
- **.env.template**: Template for environment variables needed to configure the application.
- **.env**: Contains sensitive configuration details (API keys, database URI).
- **ai_architect.db**: SQLite database file created at runtime to store user and essay data.
- **templates/**: Directory containing HTML files for various application views.
- **README.md**: Comprehensive documentation for installation, usage, and features.
- **start.bat**: Batch file to automate the setup process on Windows.

# Technology Stack
- **Backend**: Flask (Python), Flask-SQLAlchemy (SQLite DB), Flask-Login for authentication.
- **Frontend**: HTML/JavaScript with Server-Sent Events (SSE) for real-time updates.
- **File Handling**: PyPDF2 for PDF parsing, python-docx for Word document processing.
- **Payments**: Stripe for payment processing.
- **AI Models**: Claude 3.5 Sonnet, GPT-4o, Gemini 1.5 Pro.

# Usage
### Installation Steps
1. **Clone or create the project directory**:
   ```bash
   mkdir ai-assignment-architect
   cd ai-assignment-architect
   ```

2. **Create a virtual environment**:
   ```bash
   python -m venv venv
   venv\Scripts\activate  # Windows
   ```

3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Configure environment variables**:
   ```bash
   # Copy the template
   copy .env.template .env
   # Edit .env and add your API keys
   notepad .env
   ```

5. **Initialize the database**:
   ```bash
   python app.py
   ```

### Running the Application
Start the application:
```bash
python app.py
```

### Using the Application
1. Login using the provided credentials.
2. Access the control center to select tools (The Architect, The Detective, The Oracle, The Grader).
3. Follow the prompts for each tool to upload documents or enter text and complete the associated tasks.
