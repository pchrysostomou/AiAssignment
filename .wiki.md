# Project Summary
The Academic Board is a premium SaaS platform designed to enhance academic writing by providing users with the ability to generate high-quality essays through an interactive system featuring "Professors" instead of AI agents. This platform leverages advanced AI models to draft, refine, and optimize essays, while also offering features such as document uploads, payment processing through Stripe, and progress tracking. The pricing model allows users to select essay lengths with flexible payments based on word count, making the service accessible and user-friendly.

# Project Module Description
The application consists of several key modules:
- **User Management**: Handles user registration and authentication with Flask-Login.
- **Essay Generation**: Utilizes AI models (Claude 3.5 Sonnet, GPT-4o, Gemini 1.5 Pro) to create and refine essays.
- **File Upload & Parsing**: Supports drag-and-drop uploads of `.pdf` and `.docx` files for text extraction.
- **Stripe Payments**: Manages payments based on a tiered model linked to word count.
- **Real-time Streaming**: Provides live updates on essay generation via Server-Sent Events (SSE).
- **Database Management**: Employs SQLite to store user data, essays, and payment records.

# File Description Inventory
- **app.py**: Core application logic, including routes, user management, essay generation, file handling, and payment processing.
- **requirements.txt**: Lists necessary Python libraries for the application, including Stripe, PyPDF2, and python-docx.
- **.env.template**: Template for environment variables needed to configure the application.
- **.env**: Contains sensitive configuration details (API keys, database URI).
- **ai_architect.db**: SQLite database file created at runtime to store user and essay data.
- **templates/login.html**: HTML template for user login and registration.
- **templates/dashboard.html**: HTML template for the main user interface to generate essays and view history.
- **README.md**: Comprehensive documentation for installation, usage, and features.
- **start.bat**: Batch file to automate the setup process on Windows.

# Technology Stack
- **Backend**: Flask (Python), Flask-SQLAlchemy (SQLite DB), Flask-Login for authentication.
- **Frontend**: HTML/JavaScript with Server-Sent Events (SSE) for real-time updates.
- **File Handling**: PyPDF2 for PDF parsing, python-docx for Word document processing.
- **Payments**: Stripe for payment processing.
- **AI Models**: Claude 3.5 Sonnet, GPT-4o, Gemini 1.5 Pro.

# Usage
### Installation Steps
1. **Clone or create the project directory**:
   ```bash
   mkdir ai-assignment-architect
   cd ai-assignment-architect
   ```

2. **Create a virtual environment**:
   ```bash
   python -m venv venv
   venv\Scripts\activate  # Windows
   ```

3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Configure environment variables**:
   ```bash
   # Copy the template
   copy .env.template .env
   # Edit .env and add your API keys
   notepad .env
   ```

5. **Initialize the database**:
   ```bash
   python app.py
   ```

### Running the Application
Start the application:
```bash
python app.py
```

### Using the Application
1. Login using the provided credentials.
2. Upload your essay file or enter your essay instructions and select the target word count.
3. Click "Pay & Generate Essay" to proceed with payment and generation.
