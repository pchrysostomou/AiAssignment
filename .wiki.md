# Project Summary
The Academic Suite is a revolutionary SaaS platform designed to enhance academic writing while maintaining educational integrity. Leveraging advanced AI technologies, it provides tools for essay generation, plagiarism detection, content analysis, and grading, all integrated with payment management through Stripe. The platform features dynamic pricing based on word count and tool usage, with continuous improvements focused on performance, user experience, and security.

# Project Module Description
The application consists of the following key modules:
- **User Management**: Handles user registration and authentication.
- **Essay Generation (The Architect)**: Generates essays with citation verification, utilizing Google Custom Search for real-time research.
- **Plagiarism Checking (The Detective)**: Conducts plagiarism checks and produces detailed PDF reports.
- **AI Detection (The Oracle)**: Identifies AI-generated content and provides a probability score.
- **Strict Grading (The Grader)**: Evaluates essays through consensus from multiple AI models.
- **File Upload & Parsing**: Supports drag-and-drop uploads for `.pdf`, `.docx`, and `.txt` files, with a 25MB size limit.
- **Stripe Payments**: Manages payments based on tool usage, including promo code support.
- **Real-time Streaming**: Provides live updates during essay generation and processing.
- **AI Support Bot (The Concierge)**: Offers user assistance via a chat interface.

# File Description Inventory
- **app.py**: Core application logic, including user management, tool operations, payment processing, and AI model integration.
- **requirements.txt**: Lists necessary Python libraries for the application, including Stripe and file handling libraries.
- **Procfile**: Specifies how to run the application in production using Gunicorn.
- **.env.template**: Template for environment variables needed to configure the application.
- **.env**: Contains sensitive configuration details (API keys, database URI).
- **ai_architect.db**: SQLite database file created at runtime to store user and essay data.
- **templates/**: Directory containing HTML files for various application views.
- **README.md**: Comprehensive documentation for installation, usage, and features.
- **start.bat**: Batch file to automate the setup process on Windows.

# Technology Stack
- **Backend**: Flask (Python), Flask-SQLAlchemy (SQLite DB), Flask-Login for authentication.
- **Frontend**: HTML/JavaScript with Server-Sent Events (SSE) for real-time updates.
- **File Handling**: PyPDF2 for PDF parsing, python-docx for Word document processing.
- **Payments**: Stripe for payment processing, supporting promo codes.
- **AI Models**: Claude Opus 4.5 (primary), Claude Opus 4 (fallback), GPT-4o, Gemini 1.5 Pro.
- **Production Server**: Gunicorn for deployment.

# Usage
### Installation Steps
1. **Clone or create the project directory**:
   ```bash
   mkdir ai-assignment-architect
   cd ai-assignment-architect
   ```

2. **Create a virtual environment**:
   ```bash
   python -m venv venv
   venv\Scripts\activate  # Windows
   ```

3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Configure environment variables**:
   ```bash
   # Copy the template
   copy .env.template .env
   # Edit .env and add your API keys
   notepad .env
   ```

5. **Initialize the database**:
   ```bash
   python app.py
   ```

### Running the Application
Start the application:
```bash
python app.py
```

### Using the Application
1. Log in using the provided credentials.
2. Access the control center to select tools (The Architect, The Detective, The Oracle, The Grader).
3. Follow the prompts for each tool to upload documents or enter text and complete the associated tasks.
