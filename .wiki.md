# Project Summary
The Academic Suite is an advanced SaaS platform designed to enhance academic writing and integrity by providing users with a suite of tools for essay generation, plagiarism checking, AI detection, and strict grading. It utilizes sophisticated AI models to produce high-quality essays while ensuring adherence to citation standards. The platform supports document uploads and payment processing through Stripe, offering flexible payment options based on word count and tool selection.

# Project Module Description
The application consists of several key modules:
- **User Management**: Handles user registration and authentication using Flask-Login.
- **Essay Generation (The Architect)**: Produces essays with a focus on citation verification and human-like writing styles using AI models.
- **Plagiarism Checking (The Detective)**: Scans uploaded text or files for potential plagiarism and generates detailed PDF reports.
- **AI Detection (The Oracle)**: Analyzes text to identify AI-generated content and provides a probability score.
- **Strict Grading (The Grader)**: Evaluates student essays against assignment briefs using multiple AI models for comprehensive feedback.
- **File Upload & Parsing**: Supports drag-and-drop uploads of `.pdf`, `.docx`, and `.txt` files for text extraction.
- **Stripe Payments**: Manages payments based on tool usage with tiered pricing.
- **Real-time Streaming**: Offers live updates on essay generation and tool processing via Server-Sent Events (SSE).
- **Database Management**: Utilizes SQLite to store user data, essays, reports, and payment records.

# File Description Inventory
- **app.py**: Core application logic, including routes for user management, tool operations, and payment processing.
- **requirements.txt**: Lists necessary Python libraries for the application, including Stripe, reportlab, and file handling libraries.
- **.env.template**: Template for environment variables needed to configure the application.
- **.env**: Contains sensitive configuration details (API keys, database URI).
- **ai_architect.db**: SQLite database file created at runtime to store user and essay data.
- **templates/login.html**: HTML template for user login and registration.
- **templates/dashboard.html**: HTML template for the main user interface to access tools and view history.
- **README.md**: Comprehensive documentation for installation, usage, and features.
- **start.bat**: Batch file to automate the setup process on Windows.

# Technology Stack
- **Backend**: Flask (Python), Flask-SQLAlchemy (SQLite DB), Flask-Login for authentication.
- **Frontend**: HTML/JavaScript with Server-Sent Events (SSE) for real-time updates.
- **File Handling**: PyPDF2 for PDF parsing, python-docx for Word document processing.
- **Payments**: Stripe for payment processing.
- **AI Models**: Claude 3.5 Sonnet, GPT-4o, Gemini 1.5 Pro.

# Usage
### Installation Steps
1. **Clone or create the project directory**:
   ```bash
   mkdir ai-assignment-architect
   cd ai-assignment-architect
   ```

2. **Create a virtual environment**:
   ```bash
   python -m venv venv
   venv\Scripts\activate  # Windows
   ```

3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Configure environment variables**:
   ```bash
   # Copy the template
   copy .env.template .env
   # Edit .env and add your API keys
   notepad .env
   ```

5. **Initialize the database**:
   ```bash
   python app.py
   ```

### Running the Application
Start the application:
```bash
python app.py
```

### Using the Application
1. Login using the provided credentials.
2. Access the control center to select tools (The Architect, The Detective, The Oracle, The Grader).
3. Follow the prompts for each tool to upload documents or enter text and complete the associated tasks.
